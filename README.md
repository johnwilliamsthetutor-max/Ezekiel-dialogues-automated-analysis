The dialogues are, here, data to be analyzed.  
The dialogues are between a human and a succession of Claude models, covering a succession of chapters of the book of Ezekiel.
The this phase of the project is both an attempt to learn about the models which had the dialogues, the dialogues themselves, and so on.
but also an a test of an automated analysis system, designed in collaboration with Claude Fable 5, but largely built with Claude Opus 5.
The analysis itself will be a mix of automated script and LLM reading, with cross connection and logging.
